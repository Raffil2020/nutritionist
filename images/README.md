## Image Guidelines

### Optimization
- Compress all images before uploading
- Use WebP format for better compression (with JPG fallback)
- Maximum file size: 200KB per image
- Use tools like TinyPNG or ImageOptim

### Dimensions
- Portfolio images: 600x400px (3:2 ratio)
- About section: 800x600px (4:3 ratio)
- Hero background: 1920x1080px (optional, currently using CSS gradient)

### Naming Convention
- Use lowercase
- Use hyphens instead of spaces
- Be descriptive: `backyard-patio-installation.jpg`

## Placeholder Images

Until you add your own images, the CSS includes gradient backgrounds for placeholder images. Once you add real images with the names listed above, they will automatically replace the placeholders.

## WordPress Migration Note

When migrating to WordPress, these images will be moved to the WordPress media library and referenced through the theme templates.
