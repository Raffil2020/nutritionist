== Description ==

Long Beach Landscaping is a modern, professional WordPress theme designed specifically for landscaping, lawn care, and outdoor design businesses. Perfect for showcasing your portfolio, services, and client testimonials.

= Features =

* Responsive Design - Mobile-first approach
* Portfolio Gallery - Filterable project showcase with categories
* Services Section - Highlight your landscaping services
* Testimonials Slider - Display client reviews
* Contact Form - Built-in AJAX contact form
* Custom Post Types - Portfolio, Services, Testimonials
* Custom Taxonomies - Portfolio Categories
* Theme Customizer - Easy customization options
* Widget-Ready Footer - 4 footer columns
* SEO Optimized - Clean, semantic HTML5
* Fast Loading - Optimized performance
* Translation Ready - Full i18n support

= Custom Post Types =

* Portfolio - Showcase your landscaping projects
* Services - Display your service offerings
* Testimonials - Feature client reviews

= Customizer Options =

* Hero Section - Customize title and subtitle
* Contact Information - Set address, phone, email
* Custom Logo - Upload your business logo
* Custom Colors - Match your brand

== Installation ==

1. Upload the theme ZIP file via Appearance > Themes > Add New > Upload Theme
2. Activate the theme through the 'Themes' menu in WordPress
3. Go to Appearance > Customize to configure theme settings
4. Create your content (Portfolio items, Services, Testimonials)
5. Set a static front page: Settings > Reading > Front page displays > A static page

== Frequently Asked Questions ==

= How do I add portfolio items? =

Go to Portfolio > Add New in your WordPress admin. Add a title, description, featured image, and assign a portfolio category (Residential, Commercial, Hardscape, Maintenance).

= How do I customize the hero section? =

Go to Appearance > Customize > Hero Section. You can change the hero title and subtitle text.

= How do I set up the contact form? =

The contact form is built-in and works automatically. Make sure your WordPress admin email is set correctly in Settings > General.

= Can I change the colors? =

Yes! Edit the CSS variables in style.css or add custom CSS via Appearance > Customize > Additional CSS.

= How do I add testimonials? =

Go to Testimonials > Add New. The title should be the client name, the content is the testimonial text, and the excerpt is for location/title.
